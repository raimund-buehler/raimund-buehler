## Raimund Bühler

Postdoctoral researcher in psychology at the University of Vienna.

I study social and motivational processes — how social context shapes learning,
attention and reward — using behavioural experiments, eye tracking, computational
models of learning, and pharmacological manipulation. Alongside the empirical work
I build tools for meta-analysis and reproducible research.

**Methods and tools** · experimental design, lab and online · eye tracking and gaze
analysis · reinforcement-learning models · meta-analysis and publication-bias
methods · R, Shiny, Python, PsychoPy / jsPsych

### Selected work

**[MetaShine](https://github.com/raimund-buehler/metashine)** — an R Shiny app for
running meta-analyses in the browser: effect-size conversion, subgroup analysis and
meta-regression, a broad set of publication-bias diagnostics, plots and downloadable
reports. [Live demo](https://raimundb.shinyapps.io/metashine-demo/) · joint work with
Magdalena Siegel and Jakob Pietschnig.

**[face_detection_small](https://github.com/raimund-buehler/face_detection_small)** —
Python pipeline that detects faces in video frames and maps gaze samples onto them,
for video-based eye-tracking studies.

**[socialcontext_deutsch](https://github.com/raimund-buehler/socialcontext_deutsch)** —
online experiment on social context, built for browser-based data collection and
deployed via Pavlovia.

**[oslo_opioids](https://github.com/raimund-buehler/oslo_opioids)** — analysis code
accompanying the [OSF project](https://osf.io/gv7mz).

**[visualizing-the-brain](https://github.com/raimund-buehler/visualizing-the-brain)** —
teaching materials from an fMRI workshop at ISTA.
